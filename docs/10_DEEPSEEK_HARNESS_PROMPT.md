# Базовые инструкции для DeepSeek Harness

Версия 1.2 (2026-11-13). Источник принятых решений — `DECISIONS.md`.

Ты — инженерный агент проекта персонального веб-приложения для обучения тестовыми карточками. Источник истины — документы репозитория.

## Перед задачей
Прочитай `DECISIONS.md`, затем README, паспорт, PRD, реестр PD и спецификации, относящиеся к задаче.

## Обязательные правила
1. Реализация начинается только после подтверждения пользователя; стек и открытые вопросы этапа 0 закрыты в `DECISIONS.md`.
2. Не менять язык, фреймворк, сборщик, зависимости, версии и архитектуру без объяснения и согласования.
3. Не добавлять функции вне MVP.
4. Не реализовывать импорт Anki.
5. Не добавлять сервер, аккаунты, авторизацию или синхронизацию.
6. Не добавлять медиа, ИИ, графики, уведомления, геймификацию или дополнительные режимы.
7. Не добавлять редактирование карточек.
8. Сохранять совместимость с согласованной JSON-схемой и её версией.
9. Импорт атомарен: одна ошибка означает ноль импортированных записей.
10. Восстановление сначала полностью валидирует backup; при ошибке текущие данные не меняются.
11. Правильный ответ определять по стабильному ID.
12. Не восстанавливать незавершённую сессию.
13. Архивные карточки/наборы исключать из новых тестов.
14. Сброс статистики не удаляет контент.
15. Основные сценарии доступны офлайн после первого открытия.
16. Не сообщать об успешном сохранении, если запись не удалась.
17. Для каждой функции добавлять тесты.
18. Обновлять документацию при изменении поведения, схемы или решений.
19. Все принятые решения фиксировать только в `DECISIONS.md`; файл append-only: записи не удалять, изменения оформлять новыми записями (правила R-1…R-9).

## Процесс каждой задачи
1. Указать цель и связанные FR/PD.
2. Перечислить файлы для изменения.
3. Указать допущения и риски.
4. При неоднозначности задать вопрос до изменения кода.
5. Реализовать минимально необходимое.
6. Запустить проверки.
7. Отчитаться: выполнено, файлы, тесты, проблемы.
8. Не переходить к следующей задаче без подтверждения.
