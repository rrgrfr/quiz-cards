# Паспорт проекта

Версия 1.2 (2026-11-13). Источник принятых решений — `DECISIONS.md`.

## Описание
Персональное мобильное веб-приложение «Карточки» (internal id `personal-quiz`) для обучения тестовыми карточками. Пользователь создаёт наборы или импортирует их из собственного JSON, запускает тест и выбирает один правильный ответ из четырёх. Обратная связь появляется сразу после выбора, после теста — краткий итог.

## Цели MVP
- Создание наборов и карточек.
- Импорт и экспорт собственного JSON.
- Тестирование с четырьмя вариантами ответа.
- Мгновенная обратная связь и краткий итог.
- Базовая статистика по приложению, наборам и карточкам.
- Локальное хранение и работа офлайн после первой загрузки.
- Полное резервное копирование в один JSON-файл.

## Платформа
- iPhone, Safari 16.4+.
- Мобильное веб-приложение; статический хостинг с HTTPS.
- Установка как PWA не обязательна, но рекомендуется (снижает риск очистки данных iOS).
- Первый запуск требует интернет; после успешной загрузки основные функции доступны офлайн.
- Данные хранятся локально (LocalStorage); приложение не гарантирует сохранность при очистке данных браузером.

## Не входит в MVP
Облачная синхронизация, аккаунты, ИИ-генерация, изображения/аудио/видео, сложная аналитика и графики, уведомления, геймификация, дополнительные режимы обучения, импорт Anki и `.apkg`, редактирование карточек и наборов, hard delete, шифрование локальных данных.

## Принципы
Минимум действий, тёмная тема, минималистичный стиль в эстетике Apple, локальность, предсказуемость, простота реализации. Никаких дополнительных функций без согласования.

## Техническая рамка
TypeScript + Vite + нативный DOM; LocalStorage с адаптером под будущий IndexedDB; собственный Service Worker; Git + GitHub Pages. Детали и причины — в `DECISIONS.md` (D-010…D-035, D-100…D-113).
