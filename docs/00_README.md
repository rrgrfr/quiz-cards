# Пакет документов проекта

Версия 1.8. Статус: этапы 1–6 реализованы (автоматическая часть стабилизации завершена); ручной чек-лист на iPhone и инициализация git ожидают пользователя.

## Состав
- `DECISIONS.md` — единственный источник принятых решений (append-only).
- `01_PROJECT_BRIEF.md` — паспорт и границы продукта.
- `02_PRD.md` — требования и пользовательские сценарии.
- `03_DECISION_REGISTER.md` — реестр PD-001—PD-048.
- `04_UX_SPEC.md` — экраны и поведение интерфейса.
- `05_TECHNICAL_SPEC.md` — архитектура и технические ограничения.
- `06_DATA_AND_JSON_FORMAT.md` — модель данных и форматы JSON.
- `07_TEST_STRATEGY.md` — тестирование и критерии приёмки.
- `08_IMPLEMENTATION_PLAN.md` — этапы разработки.
- `09_RISKS_AND_OPEN_QUESTIONS.md` — риски и открытые вопросы.
- `10_DEEPSEEK_HARNESS_PROMPT.md` — инструкции агенту.

## Правила
1. Не начинать реализацию без подтверждения пользователя и без опоры на `DECISIONS.md`.
2. Не менять утверждённые решения молча.
3. Отделять продуктовые требования от технических рекомендаций.
4. При неоднозначности задавать вопрос, а не додумывать.
5. Не добавлять функции вне MVP.
6. При конфликте приоритет имеет `DECISIONS.md`, затем `03_DECISION_REGISTER.md`, PRD, техническая спецификация и UX.
7. Решения фиксируются только в `DECISIONS.md`; файл append-only — записи не удаляются, изменения оформляются новыми записями.

Технические детали MVP выбраны и зафиксированы в `DECISIONS.md`; изменения — только новыми записями по правилам R-1…R-9.
