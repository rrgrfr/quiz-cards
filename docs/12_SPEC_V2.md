Версия 1.1 (2026-11-14). Статус: к реализации; решения Q-01…Q-04 подтверждены пользователем.
Основание: `11_ANALYSIS_AND_IMPROVEMENTS.md`. Источник решений — `DECISIONS.md`.

Ключевое решение по набору (Q-01): **набор хранится в коде как пример возможностей приложения**.
Он не добавляется в состояние автоматически, для него нет кнопки и отдельного экрана; файл доступен
для ручного импорта через «Настройки» и как часть поставки.

## 2. Функция V2-F-01 — ползунок количества вопросов

### 2.1 Требования

| ID | Требование |
|---|---|
| V2-FR-01 | На экране «Настройка теста» вместо stepper — нативный `input[type="range"]` с `min=1`, `max=N`, `step=1`, где `N` — число активных карточек набора |
| V2-FR-02 | Значение по умолчанию — `min(10, N)` (сохраняется правило D-060) |
| V2-FR-03 | Выбранное число видно над ползунком и обновляется при каждом движении |
| V2-FR-04 | «Начать тест» передаёт выбранное число в существующий маршрут `{ name: 'test', deckId, count }` |
| V2-FR-05 | При `N = 1` ползунок заблокирован, значение `1`, тест запускается |
| V2-FR-06 | При `N = 0` показывается существующий экран-заглушка «Нет активных карточек»; поведение не меняется |
| V2-FR-07 | Доступность: у ползунка есть доступное имя, значение читается VoiceOver, зона касания ≥44 pt (D-088) |
| V2-FR-08 | Значение не запоминается между сессиями: при каждом входе — `min(10, N)` (запоминание — задача U-09) |

### 2.2 UX и поведение

```
Настройка теста
Доступно 239 карточек

Сколько вопросов?
        10
[—————————o———————————————————————]
[          Начать тест            ]
```

| Ситуация | Ползунок | Значение | «Начать тест» |
|---|---|---|---|
| `N = 0` | экран-заглушка, контролов нет | — | — |
| `N = 1` | `disabled`, `min = max = 1` | 1 | активна, тест из 1 вопроса |
| `1 < N < 10` | `max = N`, стоит в конце | `N` | активна |
| `N ≥ 10` | `max = N`, стоит на 10 | 10 | активна |
| Перетаскивание | значение меняется | обновляется `input`-событием | активна |
| Стрелки клавиатуры | ±1 | обновляется | активна |

Почему значение над шкалой, а не сбоку: на ширине iPhone (~343 px) шкала получает полную ширину,
это важно при 239 и более значениях; крупное число читается как основной результат выбора.
Почему без `aria-live`: нативный `range` сам объявляет значение VoiceOver, живой регион дал бы
двойное озвучивание.

### 2.3 Правило домена

Новый файл `src/domain/test-count.ts` — единственное место, где задан дефолт (D-060):

```ts
/** Default number of questions on the test setup screen (D-060). */
export const DEFAULT_TEST_COUNT = 10;

/** Initial slider value: min(10, N); 0 when the pool is empty. */
export function initialTestCount(available: number): number {
  return Math.max(0, Math.min(DEFAULT_TEST_COUNT, available));
}
```

`TestSession` уже зажимает `count` в `1…N` — второй защиты не добавляем.

### 2.4 Экран

Файл `src/ui/screens/test-setup.ts` заменяется целиком (остальные экраны не меняются):

```ts
import type { Store } from '../../application/store';
import { findDeck } from '../../domain/entities';
import { initialTestCount } from '../../domain/test-count';
import { STRINGS } from '../../shared/strings';
import { el } from '../dom';
import type { Navigation } from '../navigation';
import { renderMessageScreen } from './message';

export function renderTestSetup(store: Store, nav: Navigation, deckId: string): HTMLElement {
  const state = store.get();
  const deck = findDeck(state, deckId);
  const available = state.cards.filter((card) => card.deckId === deckId && !card.isArchived);

  if (!deck || deck.isArchived || available.length === 0) {
    return renderMessageScreen(STRINGS.test.setupTitle, STRINGS.test.noCards);
  }

  let count = initialTestCount(available.length);

  const screen = el('section', 'screen');
  const title = el('h2', 'screen-title');
  title.textContent = STRINGS.test.setupTitle;

  const hint = el('p', 'screen-note');
  hint.id = 'count-hint';
  hint.textContent = STRINGS.test.countHint(available.length);

  const countTitle = el('h3', 'section-title');
  countTitle.id = 'count-title';
  countTitle.textContent = STRINGS.test.countTitle;

  const value = el('output', 'count-value');
  value.setAttribute('for', 'count-slider');

  const slider = el('input', 'count-slider');
  slider.type = 'range';
  slider.id = 'count-slider';
  slider.min = '1';
  slider.max = String(available.length);
  slider.step = '1';
  slider.value = String(count);
  slider.disabled = available.length === 1;
  slider.setAttribute('aria-labelledby', 'count-title');
  slider.setAttribute('aria-describedby', 'count-hint');

  const start = el('button', 'primary-button');
  start.type = 'button';
  start.textContent = STRINGS.test.start;

  const update = (): void => {
    value.textContent = String(count);
  };

  slider.addEventListener('input', () => {
    count = Number(slider.value);
    update();
  });

  start.addEventListener('click', () => {
    nav.push({ name: 'test', deckId, count });
  });

  update();
  screen.append(title, hint, countTitle, value, slider, start);
  return screen;
}
```

Новые строки не добавляются: имя ползунка берётся из существующего `STRINGS.test.countTitle`
(`aria-labelledby`), подсказка — из `STRINGS.test.countHint`.

В `src/ui/styles.css` удалить неиспользуемые после замены правила `.stepper`, `.stepper-button`,
`.stepper-button:disabled`, `.stepper-value` и добавить:

```css
.count-value {
  font-size: 32px;
  font-weight: 700;
  text-align: center;
  font-variant-numeric: tabular-nums;
}

.count-slider {
  width: 100%;
```

`accent-color` поддерживается Safari 15.4+ (целевая версия — 16.4+); трек и бегунок отрисовываются

### 2.6 Критерии приёмки

1. На экране настройки теста нет кнопок `−`/`+`; есть ползунок и крупное число.
2. Дефолт для набора из 239 карточек — 10; для набора из 3 — 3; для 1 — 1 и `disabled`.
3. Перетаскивание до конца запускает тест на 239 вопросов; итог показывает 239.
4. VO: «Сколько вопросов?, 10, Доступно 239 карточек»; изменение значения озвучивается.
5. Возврат из результата «К набору» → «Начать тест» снова показывает 10.
6. Набор без активных карточек по-прежнему показывает заглушку.
