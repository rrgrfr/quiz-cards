# UX-спецификация

Версия 1.2 (2026-11-13). Источник принятых решений — `DECISIONS.md` (D-080…D-095).

## Визуальные правила
- Только тёмная тема; переключателя нет (D-090).
- Системный шрифт (`-apple-system`, SF Pro), отступы 16 pt, радиус 12 pt, без градиентов и декоративной перегрузки (D-095).
- Mobile-first, управление касанием одной рукой, учёт safe-area и «челки» (D-019).
- Наборы — визуальные карточки; архив — отдельно, без геймификации и анимаций-наград.
- Базовые правила доступности: кнопки ≥44 pt, контраст ≥4.5, Dynamic Type, подписи VoiceOver (D-088).

## Нижняя навигация
Три вкладки, названия и иконки зафиксированы (D-080):
1. **Наборы** — главный экран.
2. **Статистика** — общая и по наборам.
3. **Настройки** — импорт, экспорт, восстановление, сброс статистики, подсказки.

Иконки — собственные SVG, без иконочных библиотек. URL-роутера нет: экраны живут в памяти, системная кнопка «назад» выходит из приложения (D-089).

## Экран «Наборы» (главный)
- Заголовок раздела, карточки активных наборов (название, число активных карточек), кнопка создания набора, вход в архив.
- Под кнопкой «Создать набор» — кнопка «Выбрать готовый» и пояснение, что можно выбрать из готовых наборов (D-138).
- Сортировка: новые сверху (`createdAt` desc); архивные в список не попадают (D-027).
- Пустое состояние: короткое объяснение и кнопка «Создать набор» (D-081).
- Долгое название обрезается двумя строками.

## Готовые наборы
- Открываются с экрана «Наборы» кнопкой «Выбрать готовый».
- Список: название, описание, число карточек; действие «Добавить».
- После добавления — переход к набору; повторно набор не добавляется: «Уже добавлен» и «К набору»; архивный — «В архиве» и «Открыть архив» (D-138).
- Ошибка загрузки или разбора файла: сообщение, состояние не меняется; набор остаётся доступным для повторной попытки.

## Создание набора
- Обязательное название (1–120 символов после trim), необязательное описание (до 200) (D-082).
- Кнопки «Сохранить» и «Отмена»; пустое название — сообщение об ошибке, сохранение блокируется.
- Редактирование набора в v1 отсутствует (D-084).

## Экран набора
- Название, описание (если есть), счётчик активных карточек, список активных карточек.
- Действия: «Начать тест», «Добавить карточку», «Архивировать набор», «Архив карточек» (D-082).
- Архивирование набора не архивирует карточки; тест доступен только у активного набора (D-085).
- Пустое состояние списка карточек: подсказка добавить первую карточку.

## Создание карточки
- Поля: вопрос (1–500), четыре варианта ответа (по 1–200), выбор ровно одного правильного (radio), объяснение (до 1000, необязательно) (D-045, D-046).
- Все тексты обрезаются по краям; пустые значения и дубли вариантов без учёта регистра — ошибка.
- Редактирование существующей карточки отсутствует (PD-021); исправление — архив старой и новая карточка.
- У полей ответов отключены автокоррекция и автозаглавные буквы; клавиатура не перекрывает поля (D-087).

## Экран карточки (read-only)
- Вопрос, четыре варианта с отметкой правильного, объяснение (если есть), история последних 20 попыток, кнопка «Архивировать» (D-083).
- История показывает дату ответа и результат; при отсутствии попыток — «Пока нет ответов».

## Настройка теста
- Ползунок количества вопросов от 1 до числа активных карточек; выбранное число видно над шкалой; значение по умолчанию `min(10, N)` (D-060, D-135).
- При 1 активной карточке ползунок заблокирован и показывает 1.
- При 0 активных карточек запуск заблокирован с подсказкой.
- Кнопка «Начать тест».

## Экран теста
- Прогресс-бар «отвечено/запланировано», номер вопроса и общее число, число верных в текущей сессии (D-066).
- Вопрос и четыре кнопки-варианта.
- Первое нажатие фиксирует ответ: кнопки блокируются, повторное нажатие игнорируется (guard 300 мс) (D-063).
- После ответа: подсветка правильного и выбранного, объяснение при наличии; кнопка «Далее», на последнем вопросе — «Итог» (D-064).
- Выход (назад или смена вкладки) — подтверждение «Прервать тест? Результат не сохранится»; после подтверждения попытки отбрасываются (D-065).

## Итог
- Верные, неверные, процент по формуле `round(верные / ответы × 100)`; при нуле ответов — «—» (D-070).
- Кнопки «К набору» и «Ещё раз» (D-067).
- Графики, награды и ИИ-рекомендации не показываются.

## Статистика
- Общая карточка: завершённые тесты, верные, неверные, процент.
- Список активных наборов с теми же показателями; архивные скрыты (D-071).
- История по карточке доступна на экране карточки (D-072).
- Пустое состояние: «Пока нет завершённых тестов».

## Архив
- Отдельный экран: архивные наборы и архивные карточки, восстановление по одной сущности (D-086).
- Восстановление возвращает сущность в активные списки и статистику.
- Массовых операций нет.

## Импорт
- Выбор JSON-файла, полная валидация, список ошибок (до 20) с номером карточки и полем; при ошибке — ноль изменений (D-048).
- При совпадении названия набора — предупреждение и подтверждение, затем создаётся отдельный набор (D-043).
- Успех: сообщение и переход к импортированному набору.
- Готовый набор `qa-core-239` (239 карточек) доступен на экране «Наборы» → «Выбрать готовый» (D-138); файл также можно импортировать вручную из `public/decks/qa-core-239.json`.

## Экспорт и восстановление
- Экспорт: предупреждение, что файл не шифруется (D-057, D-092), затем скачивание `quiz-backup-ГГГГ-ММ-ДД-ЧЧмм.json`; резервный вариант — share (D-055).
- Восстановление: выбор файла, валидация, подтверждение с количеством наборов/карточек/сессий, замена данных (D-053).
- Ошибка валидации: сообщение, текущие данные не меняются.

## Настройки
- Разделы: «Импорт», «Экспорт», «Восстановление», «Сброс статистики», подсказка про установку на экран «Домой» и регулярный экспорт (D-093).
- Пользовательских настроек нет; объекта `settings` в UI не видно (D-026).
- «Сброс статистики» удаляет сессии и попытки, контент не трогает; подтверждение с предупреждением о необратимости (D-073, D-074).

## Опасные операции и подтверждения

| Действие | Подтверждение | Необратимость |
|---|---|---|
| Восстановление из backup | Да, с количеством сущностей | Текущие данные заменяются |
| Сброс статистики | Да, предупреждение о необратимости | История удаляется |
| Выход из теста | Да, «результат не сохранится» | Попытки отбрасываются |
| Импорт с совпадающим названием | Да | Создаётся дубль по названию |
| Архивирование набора/карточки | Нет | Обратимо |

## Ошибки и сообщения
- Единый каталог текстов по кодам (D-094): импорт, backup, запись, квота, повреждённое состояние.
- Ошибка записи: явное сообщение, успех не показывается (D-031).
- Превышение квоты (>4.5 МБ): отказ с советом экспортировать данные или сбросить статистику (D-032).
- Повреждённое состояние: экран с кнопками «Скачать данные как есть» и «Сбросить» (D-030).
- Офлайн: индикатор при `navigator.onLine === false` (D-104).

## Критерии приёмки интерфейса
- Тёмная тема на всех экранах, переключателя нет.
- Все интерактивные элементы ≥44 pt, доступны с одной руки.
- Системный шрифт и указанные отступы/радиусы; эталон — согласованные скриншоты этапа 1 (D-095).
- Ни один экран не требует сети, кроме первого запуска.
