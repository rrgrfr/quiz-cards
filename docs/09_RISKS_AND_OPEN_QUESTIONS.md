## Актуальные риски и меры

| Риск | Влияние | Мера |
|---|---|---|
| Квота LocalStorage (~5 МБ) | Отказ записи, потеря нового результата | Лимиты импорта, guard 4.5 МБ, явное сообщение (D-032, D-124) |
| Очистка данных iOS/Safari | Полная потеря локальной базы | Установка на экран «Домой», регулярный экспорт, предупреждение (D-093, D-105) |
| Очистка данных Safari (пользователем) | Потеря базы и кеша | Рекомендация экспорта; приложение не обещает сохранность (D-105) |
| Обновление Service Worker | Смешивание версий ресурсов | Версия кеша, плашка «Обновить», skipWaiting (D-102) |
| Частичная запись при импорте | Повреждение данных | Валидация до записи, один setItem (D-031, D-048) |
| Ошибка в определении правильного ответа | Ломает тест | Проверка по стабильному `correctAnswerId` (D-049, D-062) |
| Повреждённый backup | Уничтожение текущих данных | Полная валидация и отказ при ошибке (D-052) |
| Несколько вкладок Safari | Рассинхронизация и потеря записи | Last-write-wins со сверкой revision (D-034) |
| Открытый текст экспорта | Утечка при передаче файла | Предупреждение перед экспортом (D-057, D-092) |
| Нет шифрования и блокировки | Доступ к данным с устройства | Принято как ограничение MVP (D-112) |
| Нет hard delete | Рост данных, невозможность удалить | Архив вместо удаления (D-130) |
| Зависимость от хостинга | Приложение недоступно при сбое хостинга | Статический хостинг с HTTPS, собственные ассеты (D-014, D-015) |

## Ограничения MVP
Только текст, четыре варианта, один правильный ответ, один режим обучения, без синхронизации, Anki, медиа, ИИ, уведомлений, геймификации и сложной аналитики. Решения об ограничениях — PD-047, PD-048, D-130…D-132.

Не менять эти ограничения без отдельного решения пользователя, оформленного новой записью в `DECISIONS.md`.
